# ASSET_PROVENANCE.md

## Policy
Every asset used by this project must have its origin and license recorded.

Nintendo-owned Mario/Zelda art, characters, models, sprites, maps, music, sound effects, logos, or ripped game data are not project assets. The project uses only high-level gameplay inspiration from NES-era adventure and platform games.

## Character Pack v0.1.0

### Authorship
The following four character meshes are original procedural designs created specifically for auxz2jz/Slot-13:
- hero_aster.glb
- enemy_moss_mite.glb
- enemy_prismwing.glb
- npc_waykeeper.glb

No third-party character geometry or textures were copied into these four models.

### Generation tool
The models are generated by:
- tools/generate_characters.py
- trimesh 4.11.1
- NumPy

trimesh is MIT licensed. Upstream repository:
- mikedh/trimesh

The project also has access to the user's fork:
- auxz2jz/trimesh

### Open-source / CC0 references inspected
These repositories were inspected as legal technical/art-direction references for later rigging, animation, and environment work:

1. KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0
   - License: CC0 1.0 Universal
   - Mobile-friendly low-poly characters
   - Rigged and animated
   - glTF/FBX support
   - No KayKit geometry was copied into Character Pack v0.1.0.

2. Ariescar/gobkit-free-assets
   - License: CC0 1.0 Universal
   - Rigged/animated low-poly GLB characters, animals, and nature assets
   - No Gobkit geometry was copied into Character Pack v0.1.0.

If files from either pack are later incorporated directly, record the exact file path, source repository, source commit/version, modification, and resulting project path here.
